# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Allternit Desktop, please report it
privately to:

**security@allternit.com**

Please include:

- A description of the vulnerability and its impact
- Steps to reproduce (proof-of-concept, if available)
- Affected version(s) and platform(s)

Do **not** open a public GitHub issue for security vulnerabilities.

## Response

- We aim to acknowledge reports within 3 business days.
- We will coordinate a fix and disclosure timeline with you before any public
  announcement.

## Scope

- Allternit Desktop application and its bundled components
- This repository's release assets and installer scripts

Out of scope: third-party services (e.g., Cloudflare) — report those to the
respective vendors.
